# AI Agent 学习笔记

按知识域系统整理的一套学习材料，覆盖 RAG 全链路、Agent 与多智能体，以及配套的后端与数据知识。

## 怎么用

浏览器打开根目录的 **`index.html`**（双击即可，纯静态、零依赖）。左侧是常驻目录，任何一页都能跳转。

也可以直接访问线上版本：**https://sandrewzq.github.io/ai-study/**

学习计划（242 题的分类与推进顺序）在 `reference/plan.html`，与材料页一样带全站侧栏，随时可跳回目录。

**242 题已全部覆盖**：A~J 十个域，分布在上面的五个步骤和两个不占步骤的专题里。

三页分工：`index.html` 回答「现在做什么、有什么、在哪」（三条动作给起步，完整目录给全站）；
`reference/plan.html` 回答「按什么顺序学」；`reference/questions.html` 回答「这道题谁讲过」。
每份材料的侧栏都有「参考」段直达后两页。

这三页**只有 `index.html` 在根目录**，另两页放在 `reference/` 里——根目录保持「一个入口」，
而这两个页面不是学习材料、是查询用的参考页，页型、导航段数、字数豁免都按「参考页」处理
（见 `plan/spec.md` 第一节）。

## 怎么找

- **搜**：点顶栏的「🔍 搜索」，或按 <kbd>/</kbd>。题号（`JR-5`）、概念（`虚拟滚动`）、页面名都能搜；命中的是章节时直接落到那一节。
- **题号反查**：`reference/plan.html` 和 `reference/questions.html` 里的题号都是链接，点一下**直接落到答这道题的那一节**（不是材料页顶部）。落到哪一节由材料页 h2 标题里写的题号决定；标题里没写的，落到该页「讲解骨架」。
- **勾完成标志**：目录页和 00 导读页底部那份「完成标志（做到这些才算过关）」清单（共 14 页）每条前面有个复选框，勾上就记在本地，清单顶上会显示「已掌握 n/N」。
- **换配色**：顶栏右侧的深/浅色按钮；不动它就跟系统走。

## 结构

- 纯静态 HTML + 共用样式表，**不需要构建、不需要起服务器**，双击 `index.html` 就能看
- 交互层（`assets/app.js`）是叠加式的：**禁掉 JS 页面照常可读**，只是没有搜索、打勾和配色按钮
- 全站无外部依赖、离线可用、适配深色模式
- 每份材料统一结构：导语 → 主图 → 正文 → 讲解骨架 → 追问预警 → 回忆卡 → 翻页
- 讲解骨架那一节的**开头有一句用法说明**（`.skelnote`）：这一节就是答案、怎么用、回忆卡怎么自测
- 材料里的 `X` / `XX` / `X%` **不是没写完**，是留给你填自己项目数字的槽位（原因见 `plan/spec.md` 第二节）
- 图示全部是内联 SVG / CSS
- 目录名与文件名一律英文，页面标题和正文保持中文
- 根目录只放 `index.html`、`README.md`、`LICENSE`、`.gitignore`、`.nojekyll`；这条白名单同时是页型判据，见 `plan/spec.md` 第一节
